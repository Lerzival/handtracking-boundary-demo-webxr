Demo que implementa la infraestructura de Vite para que, accediendo a la web a través de un navegador en unas gafas de RV/RX conectadas a la misma red, controlas un cubo con las manos en realidad extendida. La idea es asentar la lógica básica para colocar un modelo en el suelo a partir de un hit test, seleccionarlo con hand tracking para poder arrastrarlo, y seleccionándolo con dos manos, poder reescalarlo y rotarlo de la forma más natural posible. La interacción con el modelo se lleva a cabo con cursores (ray casts) que están ligados a las muñecas del usuario. En el futuro buscaré implementar lógica para transicionar del entorno real al virtual de forma natural si el modelo se sale fuera de la zona real delimitada por las gafas (el guardian).
